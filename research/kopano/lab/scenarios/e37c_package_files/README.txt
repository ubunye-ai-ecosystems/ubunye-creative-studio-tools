Kopano test (ThabangVision), version 8, about 30 minutes

1. Extract this zip to a folder (for example the Desktop). Delete the old test folder first.
2. Only on the laptop in Thabang's house, once: double-click ALLOW-same-wifi.cmd and click Yes
   when Windows asks. This lets the test work over the home Wi-Fi with the internet off.
   (It allows only this test program, only from the same Wi-Fi. REMOVE-same-wifi.cmd undoes it.)
3. Double-click the start file for this laptop:
     START-home-laptop.cmd          on the laptop in Thabang's house
     START-Soshanguve-laptop.cmd    on the laptop in Soshanguve
4. If Windows says "Windows protected your PC": click "More info", then "Run anyway".
   (The test program is not signed by a company yet.)
5. If Windows Firewall asks: tick BOTH "Private networks" and "Public networks", then "Allow".
6. Keep the laptop plugged in and awake. Leave the black window open. It shows each test step
   as Thabang's PC runs it. When it says "online", you are done; nothing else to click.
7. When Thabang says the test is finished: close the window, run REMOVE-same-wifi.cmd if you
   ran the ALLOW file, and delete the folder.

What it does: it keeps a small test project online (public sample photos and test files, no
personal files) and only follows instructions from Thabang's PC. It cannot run anything else,
it does not install anything, and it only reads (never changes) your network settings when
checking why a connection fails.
